# this_ai_is_bananas


## abstract 

"This AI Is Bananas" is a hands-on workshop exploring how Claude and Copilot fit into everyday research and reporting work, using banana price data as a deliberately low-stakes way to practice real skills. Attendees will search for and critique a genuine scientific paper, build interactive charts with AI assistance, and learn a practical framework for handling sensitive research data safely. Rather than hype or scepticism, the session focuses on what these tools actually do well, where they fall short, and how to verify their output before trusting it. Judgement stays with the researcher; the tools just get you there faster.
 
<strong><u>Bring a laptop to participate in the hands-on components of this session</u></strong>
